#RAG Document Assistant

Полноценное full-stack приложение, реализующее архитектуру Retrieval-Augmented Generation (RAG). Проект позволяет загружать текстовые документы (PDF, DOCX, TXT) и вести с ними осмысленный диалог с помощью нейросети OpenAI.

Приложение самостоятельно извлекает текст, нарезает его на семантические блоки, векторизует и сохраняет в локальную векторную базу данных для быстрого поиска релевантного контекста.

#Архитектура и стек технологий

Проект состоит из двух изолированных микросервисов, упакованных в Docker-контейнеры:

*   Backend (API): Написан на FastAPI. Отвечает за бизнес-логику:
    *   Парсинг документов (PyPDF2, python-docx).
    *   Чанкинг текста с перекрытием.
    *   Векторизация и поиск с использованием локальной БД ChromaDB.
    *   Формирование промптов и интеграция с OpenAI API (модель gpt-4o-mini).
*   Frontend (UI): Написан на Streamlit. Предоставляет интуитивно понятный веб-интерфейс в стиле мессенджера для загрузки файлов и общения с ассистентом.
*   Инфраструктура: Docker и Docker Compose обеспечивают быструю сборку и развертывание. Векторная база сохраняется на жесткий диск благодаря Docker Volumes, что предотвращает потерю данных при перезапуске.


#Как запустить локально

Для запуска проекта на вашем компьютере должен быть установлен Docker и Docker Compose.

#Шаг 1: Подготовка окружения
Клонируйте репозиторий и перейдите в корневую папку проекта. Создайте файл .env в корневой директории и добавьте в него ваш API ключ от OpenAI.

#Шаг 2: Выполните команду в терминале:
docker compose up --build

#Шаг 3: Использование сервиса
После успешного запуска сервисы будут доступны по следующим адресам:
-   Интерфейс чата (Frontend): http://localhost:8501
-   Документация API (Swagger UI): http://localhost:8000/docs
